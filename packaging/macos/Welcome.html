Willkommen bei StackLens

Dieser Installer richtet StackLens auf Ihrem Mac ein und installiert automatisch alle benötigten Laufzeit-Abhängigkeiten, soweit sie noch nicht vorhanden sind.
Sie brauchen nichts manuell vorzubereiten.

⚠️  Internetverbindung empfohlen

Falls einzelne Werkzeuge noch nicht installiert sind, lädt der Installer sie während der Einrichtung herunter. Eine aktive Internetverbindung stellt sicher, dass alles auf Anhieb eingerichtet wird.

Was wird installiert / eingerichtet?

Werkzeug Status Wozu
JRE (Java 25) automatisch Laufzeit für StackLens – direkt im App-Bundle enthalten, kein Download nötig.
Node.js 22 LTS automatisch Wird benötigt, um den integrierten MCP-Server zu starten (Jira, GitLab, GitHub …).
Git automatisch Wird für Repository-Analyse und Code-Suche verwendet.
Kotlin Compiler automatisch Wird für Kotlin-spezifische Analyse-Funktionen benötigt.
k6 automatisch Lasttest-Tool für die integrierten Performance-Tests.
Apache JMeter automatisch Weiteres Lasttest-Tool für komplexe Performance-Szenarien.
GitHub Copilot CLI manuell KI-Assistent – wird nicht automatisch installiert, da eine GitHub-Anmeldung erforderlich ist.
Einrichtung nach der Installation: gh auth login → gh extension install github/gh-copilot
Docker manuell Optional – für die Docker-basierten Demo-Umgebungen. Bitte separat von docker.com installieren.
Hinweis: Der Installer installiert fehlende Werkzeuge bevorzugt über Homebrew (falls vorhanden) und greift andernfalls auf direkte Downloads zurück. Bereits installierte Versionen werden erkannt und übersprungen. Klicken Sie auf Weiter, um die Installation zu starten.
