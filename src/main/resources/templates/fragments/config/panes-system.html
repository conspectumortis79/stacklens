        Entwickleroptionen
      

    

    

      
Diese Einstellungen steuern erweiterte UI-Funktionen. Die Änderungen werden im Browser gespeichert.

      

        

          
KI-Prompt-Buttons anzeigen

          
Zeigt auf Analyseseiten den Button zur Auswahl des KI-Prompts an.

        

        

          
        

      

      

        

          
Token-sparende Subprocess-Ausgabefilterung

          
Komprimiert Build-, Test- und Git-Ausgaben (rtk-Pattern, 63 Profile) bevor sie in den KI-Prompt gelangen. Spart typischerweise 60–80 % der Tokens in Rex- und Build-Outputs.

        

        

          
        

      

      

        

          
Token-Verbrauchs-Anzeige

          
Zeigt den Token-Verbrauch in KI-Analysen und im KI-Chat an (Input · Output · Gesamt · Dauer). Die Daten werden lokal in der H2-Datenbank gespeichert.

        

        

          
        

      

      

        

          

            
Docker Testumgebung starten

            
Zeigt in der Seitenleiste den Eintrag 'Testdocker' und startet alle Docker-Container mit allen Demos automatisch bei jedem Start von StackLens (per ./start.sh oder docker compose up).

          

          

            
          

        

        

          

            
Automatisch beim Start starten

            
Startet die Docker Testumgebung automatisch beim Start von StackLens.

          

          

            
          

        

      

    

  






  

    

      

        Browser-Speicher zurücksetzen
      

    

    

      

        
        

          Achtung: Alle gespeicherten UI-Zustände gehen verloren — geöffnete Sektionen, zuletzt gewählte Projekte, gespeicherte Lasttest-Ergebnisse und Bearer-Tokens. Die Anwendung bleibt jedoch voll funktionsfähig.
        

      

      
Setzt alle von StackLens im Browser-LocalStorage gespeicherten Einträge zurück (lt_*, cf_*). Server-seitige Daten und Konfigurationen bleiben unberührt.

      
      

    

  


  

    

      

        Datenbank auf Werkseinstellungen zurücksetzen
      

    

    

      

        
        

          Unwiderrufliche Aktion! Alle gespeicherten Daten werden gelöscht:
          
    
            
  • Alle GitLab-, Datenbank-, Confluence-, Grafana- und Jira-Verbindungen
    • 
            
  • Alle Suchsitzungen und Ergebnisse
    • 
            
  • Alle Analysen (Codequaliät, Lasttest, Sprint-Vorbereitung, SQL, JWT, Ticket)
    • 
            
  • Alle generierten Tooling-JARs
    • 
            
  • Alle Wissensdatenbanken, Dokumente, Chunks und Vektoren (RAG-Datenbank)
    • 
          

          Die Anwendung wird danach nicht mehr korrekt funktionieren, bis neue Verbindungen eingerichtet wurden.

          Sicher? Alle Daten werden unwiderruflich gelöscht. Bitte bestätige durch erneutes Klicken.
